# Email Spam Classification using Machine Learning

## Overview

This project implements a machine learning model to classify emails as Spam or Ham (Not Spam). The model is trained on a labeled dataset using Natural Language Processing (NLP) techniques and supervised learning algorithms.

---

## Objectives

- Preprocess email text
- Convert text into numerical features
- Train a spam classification model
- Evaluate model performance
- Predict whether new emails are spam or legitimate
